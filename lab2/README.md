## Частина 1. Розрахунок виразів

Для 6 варіанту з таблиці завдань потрібно обчислити три вирази:

### 1. Вираз №16
$$y = 2 \cdot \frac{\sin(a)}{\arccos(-2b)} - \sqrt{\ln(c \cdot |2d|)}$$
* **Вхідні параметри:** $a = 0.58$, $b = 0.34$, $c = 1.25$, $d = -1.89$
* **Результат обчислення:** **$y \approx -0.773413$**

### 2. Вираз №17
$$y = 2 \cdot \sqrt{|\tan(a) + c|} + \frac{\ln(b)}{c^d}$$
* **Вхідні параметри:** $a = -1.49$, $b = 23.4$, $c = 1.23$, $d = 2.254$
* **Результат обчислення:** **$y \approx 8.646448$**

### 3. Вираз №18
$$y = \frac{e^c + 2 \cdot \lg(a)}{\sqrt{c^b}} \cdot |\arcsin(d)|$$
* **Вхідні параметри:** $a = 2.34$, $b = 0.756$, $c = 2.23$, $d = -1.653$
* **Результат обчислення:** **`NaN`** *(Not a Number)*
* **Пояснення:** значення $d = -1.653$ виходить за межі проміжку $[-1; 1]$, для якого визначений $\arcsin$. Тому Java повертає `Double.NaN`.
* Якщо ж у методичці була опечатка і замість arcsin мав бути arctg (як у завданні №2): **$y \approx 7.611323$**.

## Частина 2. Відповіді на контрольні запитання

### 1. В чому полягає різниця між ключовими та зарезервованими словами?
Службові слова в Java діляться на дві групи:
- **Ключові слова** — це команди, які безпосередньо керують логікою програми та створюють її структуру (`package`, `import`, `class`, `void`, `return`, `if`, `for`, `switch`). Компільований код не працюватиме без них.
- **Зарезервовані слова** — це лексеми, які заборонено брати під назви змінних або методів, хоч вони й не виконують дій у коді. Наприклад, слова `const` та `goto` залишені «на майбутнє» (у самій мові вони не діють, але якщо так назвати змінну, код не скомпілюється). Сюди ж належать фіксовані значення `true`, `false` та `null`.

### 2. Які примітивні типи даних Ви знаєте? Для кожного з них наведіть приклади, коли найбільш ефективно використовувати саме цей тип:
Усі 8 примітивів можна згрупувати за їхнім призначенням:
* **Цілочисельні типи:**
  - `byte` (8 біт) — корисний для економії пам'яті у великих масивах, наприклад при читанні сирих байтів файлів, передачі мережевих пакетів або для зберігання коду кольору пікселя (0..255).
  - `short` (16 біт) — використовується нечасто; доречний для збереження порядкового дня в році (1..365), висоти поверху або для 16-бітних аудіодоріжок.
  - `int` (32 біти) — базовий цілий тип для 90% задач: кількість переглядів відео, лічильники в циклах, вік користувача, розмір списку.
  - `long` (64 біти) — потрібен для надвеликих чисел: вимірювання часу в наносекундах (`System.nanoTime()`), мілісекунди Unix Timestamp, розміри терабайтних дисків у байтах.
* **Дійсні (дробові) типи:**
  - `float` (32 біти) — швидкі розрахунки там, де невелика похибка не є критичною: наприклад, координати об'єктів та моделей у 3D-іграх.
  - `double` (64 біти) — висока математична точність: фізичні симуляції, тригонометричні обчислення (всі функції класу `Math`), астрономічні відстані.
* **Символьний тип:**
  - `char` (16 біт) — запис окремого знака Unicode (буква, розділовий знак, ієрогліф або код клавіші).
* **Логічний тип:**
  - `boolean` — прапорці умов (так / ні): чи користувач залогінений, чи завершено завантаження, чи активне вікно.

### 3. Що таке знакові та беззнакові типи? До якої групи відноситься кожен з примітивних типів даних?
Знак визначає, чи підтримує тип від'ємні значення:
- У знакових типах старший біт виділений під збереження знака (плюс чи мінус).
- У беззнакових типах усі розряди кодують величину числа, тому воно завжди $\ge 0$.

У мові Java майже всі типи є знаковими (`byte`, `short`, `int`, `long`, а також дробові `float` і `double`).  
Єдиним винятком серед цілих є **`char`**: він беззнаковий, тому що кодує символи в діапазоні від 0 до 65535. Тип `boolean` взагалі не є числом.

### 4. Яке максимальне число можна записати у змінну типу short, char, int, long?
- `short`: **32 767** ($2^{15} - 1$)
- `char`: **65 535** ($2^{16} - 1$, бо він беззнаковий)
- `int`: **2 147 483 647** ($2^{31} - 1$)
- `long`: **9 223 372 036 854 775 807** ($2^{63} - 1$)

### 5. Змінна типу byte може приймати значення у діапазоні -128..127. Чому цей діапазон саме такий? Чому від’ємних значень більше ніж додатних?
8 біт пам'яті дають усього $2^8 = 256$ можливих комбінацій.  
Старший біт відповідає за знак (0 — плюс, 1 — мінус).  
Через це простір чисел ділиться порівну на дві половини:
- 128 комбінацій для чисел зі знаком «мінус» (від -1 до -128).
- 128 комбінацій для чисел без мінуса. Але в цю половину обов'язково треба включити число 0 (`00000000`).  
Оскільки нуль забрав одне місце, для суто додатних чисел залишилося $128 - 1 = 127$ варіантів (від 1 до 127). Тому від'ємних чисел рівно на одне більше.

### 6. Що таке система числення? Як переводити значення з однієї системи числення у іншу?
Система числення — це набір символів і правил для позначення кількості. Вони поділяються на позиційні (значення цифри залежить від її місця в числі: двійкова, десяткова, 16-кова) та непозиційні (римські цифри).  
Як конвертувати:
- **У десяткову систему:** беремо кожну цифру числа і множимо на основу вихідної системи в степені її позиції (рахуючи справа наліво з 0), а результати додаємо.
- **З десяткової системи в іншу:** число ділимо націло на основу нової системи у стовпчик, виписуємо остачі, а отриману частку знову ділимо, доки не отримаємо нуль. Остачі, прочитані від останньої до найпершої, дають шукане число.

### 7. Що таке «Доповняльний код»?
Це спосіб, яким комп'ютери зберігають від'ємні цілі числа в двійковому вигляді.  
Щоб його скласти:
1. Записують додатне число у двійковому форматі.
2. Інвертують усі біти (кожний 0 стає 1, а кожна 1 стає 0).
3. До отриманого результату додають 1.  
Завдяки цьому процесор може виконувати операцію віднімання за допомогою тієї ж схеми, що й додавання, не вимагаючи окремого заліза для віднімання.

### 8. Пояснити результат роботи такого фрагмента коду:
```java
int a = 2_000_000_000;
int b = 2_000_000_000;
int c = a + b;
System.out.println(c);
```
**Результат:** виведеться `-294967296`.  
**Пояснення:** Математична сума дорівнює $4\,000\,000\,000$. Проте тип `int` обмежений значенням $2\,147\,483\,647$. Відбувається переповнення розрядної сітки: старший біт стає одиницею, що в системі доповняльного коду сприймається комп'ютером як мінусове число.

### 9. Чим тип float відрізняється від double?
- Пам'ять: `float` займає 4 байти, а `double` — 8 байтів.
- Точність: `float` забезпечує близько 7 значущих знаків, тоді як `double` — близько 15-16.
- Синтаксис: літерал для `float` обов'язково маркується літерою `f` наприкінці (наприклад, `4.5f`), а для `double` пишеться без додаткових суфіксів (`4.5`).

### 10. Що таке число з рухомою комою? Що таке мантиса та степінь?
Це спосіб запису дробових чисел у вигляді експоненційної форми: кома «рухається», підлаштовуючись під масштаб числа.
- **Мантиса** — це самі значущі цифри дробу, які визначають точність.
- **Степінь (порядок)** — показник, який задає масштаб і вказує, на скільки розрядів необхідно зсунути кому вліво чи вправо.

### 11. Що таке Double.NaN?
`NaN` розшифровується як *Not a Number* (не число). Це спеціальна константа, що з'являється у результаті некоректних або математично невизначених дій з дробовими числами:
- ділення нуля на нуль (`0.0 / 0.0`);
- корінь з від'ємного числа (`Math.sqrt(-9)`);
- обчислення тригонометричних функцій за межами їхнього домену, наприклад `Math.asin(-1.653)` (як у завданні №3).

### 12. Пояснити результат роботи коду:
```java
System.out.println(Double.NaN == Double.NaN);
```
**Результат:** виведе `false`.  
**Пояснення:** За правилами стандарту IEEE 754 значення `NaN` є незрівнянним і не дорівнює абсолютно нічому, навіть точно такому самому `NaN`. Перевірити, чи результат є NaN, можна за допомогою методу `Double.isNaN(...)`.

### 13. Пояснити різницю між преінкрементом та постінкрементом:
- **Преінкремент (`++x`)** спочатку додає одиницю до змінної, і лише після цього повертає нове значення у вираз.
- **Постінкремент (`x++`)** спочатку віддає старе значення для використання у виразі, і тільки після цього збільшує значення в пам'яті на 1.  
Приклад:
```java
int a = 10;
System.out.println(++a); // надрукує 11 (бо спершу збільшило)
System.out.println(a++); // надрукує 11 (віддало старе, а потім стало 12)
System.out.println(a);   // надрукує 12
```

### 14. В чому різниця між логічною та побітовою операцією AND? Чому коротка версія (&&) лише тільки логічна?
- Оператор `&` — універсальний: він обчислює обидві сторони завжди, а для чисел проводить кон'юнкцію над кожним бітом.
- Оператор `&&` — оптимізований (короткозамкнутий): якщо ліва умова вже дала `false`, праву умову комп'ютер взагалі ігнорує, бо підсумок все одно не зміниться.  
Для бітів чисел такий скорочений підхід неможливий, адже результат кожного біта залежить від обох чисел одночасно. Тому `&&` існує виключно для типу `boolean`.

### 15. В чому різниця між OR та XOR?
- **OR (`|` або `||`)** дає `true`, якщо істинним є хоча б один із операндів (або обидва одразу).
- **XOR (`^`)** дає `true` суворо тоді, коли операнди різні (один `true`, інший `false`). Якщо обидва операнди істинні — XOR повертає `false`.

### 16. Проаналізувати наступний фрагмент програми:
```java
boolean a = true && false | false;
System.out.println(a = false);
boolean b = true && false || false;
System.out.println(b = true);
```
**Результат у консолі:**
```text
false
true
```
**Чому саме так:**
1. У рядку `true && false | false` побітове `|` має вищий пріоритет за логічне `&&`. Спершу рахується `false | false` (це `false`), а потім `true && false` (виходить `false`). Змінна `a` отримує `false`.
2. У `System.out.println(a = false)` використано оператор присвоєння `=`. Змінній призначається `false`, і сам вираз повертає `false`, тому воно друкується на екран.
3. У рядку `true && false || false` оператор `&&` пріоритетніший за `||`. Спочатку `true && false` дає `false`, після чого `false || false` теж дає `false`.
4. У `System.out.println(b = true)` знову відбувається присвоєння: змінна `b` стає `true`, і вираз повертає `true`.
